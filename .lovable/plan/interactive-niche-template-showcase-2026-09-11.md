# Interactive niche template showcase

## Goal

Replace the static homepage mockup with an interactive showcase that lets visitors preview every supported local-business niche.

## Build

- Add a clear, horizontally scrollable niche selector for cleaning, landscaping, roofing, plumbing, renovation, construction, and junk removal.
- Render each choice with the existing real template engine, matching business details, copy, photography, layout, and accent color.
- Present the active template inside a polished desktop-browser frame at every screen size; on phones, scale the desktop canvas down instead of changing it into a phone layout.
- Keep the switcher easy to use on touch screens and add a restrained transition when changing niches.
- Preserve the rest of the landing page, authentication, pricing, and all backend behavior.

## Validation

- Check every niche for correct imagery, content, and accent color.
- Verify the desktop frame is readable and does not overflow at desktop and phone widths.
- Confirm the landing page remains error-free and all existing calls to action still work.
