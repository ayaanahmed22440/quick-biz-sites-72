# Distinct Template Families

## Goal

Turn the shared local-business renderer into a genuinely varied modular system while preserving every editor, preview, lead form, and publishing workflow.

## Build

- Expand the three hero-only variants into six complete page families with visibly different section order, density, service presentation, imagery, reviews, proof, and lead placement.
- Assign each niche to the family that best fits its customer journey: technical, emergency, showcase, wellness, professional, or high-energy local service.
- Replace the repeated dark three-step band with niche-aware modules. Technical trades use the selected precision methodology style; other families use results, credentials, treatment experience, case evidence, or service guarantees instead.
- Add unique process language and labels to template preset data so generated niches no longer repeat generic copy.
- Keep all existing content fields and customer customization compatible; no billing, authentication, onboarding, domain, or publishing behavior changes.  
  
DONT CHANGE THE FONT STYLES BY ALOT

## Technical details

- Extend the template preset schema with a full-page family and niche-specific feature/process data.
- Split large sections into focused renderer components inside the existing template module, then compose them by family.
- Reuse the existing four niche photos and semantic accent variable; preserve mobile layouts and preview scaling.
- Verify representative niches from every family on desktop and mobile, including image loading, overflow, links, and the quote form.
