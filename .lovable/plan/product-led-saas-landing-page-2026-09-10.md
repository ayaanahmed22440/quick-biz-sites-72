# Product-led SaaS landing page

## Goal
Replace the current service-style homepage with the selected Modern High-Contrast SaaS direction, while preserving WebWarheads pricing, navigation, authentication, and conversion paths.

## Build
- Create a centered, product-first opening with the existing $37 promise, strong local-business positioning, and clear signup and process actions.
- Show a believable WebWarheads builder demonstration directly under the headline, including editor controls, device switching, publish status, and a polished customer-site canvas.
- Restructure the remaining homepage into concise proof, capabilities, workflow, pricing, honest trust messaging, FAQ, and closing signup sections.
- Refresh the public header to match the lighter SaaS presentation while keeping authenticated and mobile behavior intact.
- Keep the existing footer, pricing component, routes, login redirects, and all backend/payment behavior working.

## Visual system
- Use the selected electric coral palette with deep ink, bright white, and pale cool surfaces.
- Use Space Grotesk for display text and DM Sans for body text.
- Favor restrained corners, thin borders, generous space, crisp typography, and small purposeful animations.
- Avoid fake customer counts, fake logos, decorative orbs, and generic dashboard placeholders.

## Validation
- Check the homepage at desktop and phone widths for overflow, legibility, navigation, and product-preview composition.
- Confirm signup, login, pricing, and how-it-works links still target the existing routes.
- Confirm the preview builds without errors.
