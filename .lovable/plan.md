# Cleaning business Meta ads landing page

## Goal
Create a separate, conversion-focused page at `/cleaning-business-websites` for US cleaning business owners. The existing homepage, checkout, onboarding, pricing, authentication, and customer websites remain unchanged.

## Page
- Build the full requested journey: cleaning-specific opening, trust problem, agency-vs-WebWarheads comparison, preview-before-payment explanation, five-step process, cleaning-site showcase, benefits, social-media comparison, homeowner scenario, FAQ, $37 offer, and final calls to action.
- Send every “Build My Website” action into the existing signup/onboarding flow and every “See How It Works” action to the existing process page.
- Use direct, honest cleaning-industry copy with no invented customers, results, reviews, urgency, or guarantees.

## Visual direction
- Combine the existing WebWarheads brand with a fresh, premium cleaning-business presentation.
- Use real cleaning photography and realistic desktop/mobile website previews drawn from the existing cleaning template system.
- Vary layouts across the page with editorial splits, comparisons, timelines, showcases, and full-width conversion bands rather than repetitive cards.
- Add restrained entrance and scroll motion with reduced-motion support.

## Technical details
- Add one new TanStack route and page-specific metadata/canonical URL.
- Reuse existing buttons, header/footer, cleaning template renderer, preview data, and signup routes.
- Add the new public route to the canonical sitemap while keeping the main homepage unchanged.

## Validation
- Verify the page at desktop and phone widths for readability, overflow, imagery, and CTA behavior.
- Confirm the main homepage is unchanged.
- Confirm the new page builds cleanly and its metadata/canonical tags are correct.
